Reset your Bookdarr password

Bookdarr does not email password resets yet. Use the steps below to regain access.

If you still have access to an admin account, go to Settings → Users and change the password there.

  1. Stop Bookdarr.
  2. Open the config.xml file in your Bookdarr data folder.
  3. Find the authentication method line, which will look like:
<AuthenticationMethod>Basic</AuthenticationMethod>
<AuthenticationMethod>Forms</AuthenticationMethod>
  1. Remove the entire AuthenticationMethod line (make sure it is not duplicated).
  2. Start Bookdarr. It should now be accessible without a password.
  3. Open the UI and set a new username/password and authentication method in Settings → General.

Docker default data folder: /config/config.xml (bind-mount /config to your host). If you are not using Docker, find the data folder shown on System → Status.

Bookdarr follows the same reset flow as Radarr, so removing the AuthenticationMethod entry is sufficient.

This is the only built-in reset flow without email. When you are done, return to Login.
