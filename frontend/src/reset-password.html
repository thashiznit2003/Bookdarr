Reset your Bookdarr password

Bookdarr does not email password resets yet. Use the steps below to regain access.

  1. Stop Bookdarr.
  2. Open the config.xml file in your Bookdarr data folder.
  3. Set authentication to none so you can log in without a password.
  4. Start Bookdarr, open the UI, and set a new username/password in Settings → General.
  5. Re-enable authentication once your new credentials are saved.

Docker default data folder: /config/config.xml (bind-mount /config to your host). If you are not using Docker, find the data folder shown on System → Status.

Example settings to add to config.xml:

<AuthenticationMethod>None</AuthenticationMethod>
<AuthenticationRequired>Disabled</AuthenticationRequired>

When you are done, return to Login.
